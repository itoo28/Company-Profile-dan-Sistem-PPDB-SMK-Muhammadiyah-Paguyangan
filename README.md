# Company-Profile-dan-Sistem-PPDB-SMK-Muhammadiyah-Paguyangan
Sistem web Company Profile dan PPDB SMK Muhammadiyah Paguyangan berbasis Laravel &amp; MySQL. Memuat profil sekolah publik, portal registrasi daring, verifikasi berkas digital, loket seragam, serta panel admin terpadu untuk staf dan calon siswa.
